# JavaScript Assignment 1

Ten separate core-JavaScript programs with comments.

1. Personalized Login Greeting
2. Multi-Type Data Summary
3. Monthly Expense Tracker
4. Academic Performance Evaluator
5. Weather Activity Planner
6. Progressive Discount System
7. Smart Guessing Game
8. Employee Salary Projection
9. Random Math Quiz Generator
10. Citizen Eligibility Validator

Run a file using Node.js, for example: `node q1_personalized_login_greeting.js`.
Change the sample values in each file to test different cases. No frameworks or external libraries are used.

Q10 interprets “eligible for all services” as citizen age 21 or older, and “eligible to vote only” as citizen age 18–20, resolving the overlap in the provided conditions.
