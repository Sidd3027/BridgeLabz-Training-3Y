Three Responsive Design Principles

Simple techniques for layouts that adapt.

Fluid Layouts

Use flexible measurements so content can grow or shrink with the screen.

width: min(100%, 900px);

Flexible Media

Keep images within their containers to prevent horizontal overflow.

img { max-width: 100%; }

Breakpoints

Adjust the layout when the available screen space becomes smaller.

@media (max-width: 600px) { ... }
