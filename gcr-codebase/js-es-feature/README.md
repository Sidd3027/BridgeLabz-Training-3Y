# Assignment 3 — Js Es Feature

Ten JavaScript programs covering data conversion, strict mode, errors, debugging, hoisting, patterns, calculator logic, JSON parsing, and closures.

## Files
1. Dynamic Data Parser
2. Employee Bonus Calculator
3. Transaction Validator
4. Debugging Mystery
5. Hoisting Lab
6. Pyramid Pattern Generator
7. Smart Calculator
8. Strict Mode Showdown
9. JSON Audit
10. Nested Hoisting and Closures

Run a file with Node.js, for example:
`node q1_dynamic_data_parser.js`

All programs use core JavaScript only and print results to the console. Debugging tasks include comments explaining where to set breakpoints and what to inspect.
