# Assignment 6 — CSS Flexbox and Grid

This assignment contains 10 responsive HTML/CSS exercises. Each question has its own HTML file and matching CSS file.

## Files
- `q1_portfolio.html` / `q1_portfolio.css` — Personal portfolio with Flexbox
- `q2_product_gallery.html` / `q2_product_gallery.css` — 4-column product gallery with CSS Grid
- `q3_three_section_homepage.html` / `q3_three_section_homepage.css` — Flexbox homepage with hover rotation
- `q4_dashboard_grid.html` / `q4_dashboard_grid.css` — Grid dashboard with a two-column tile
- `q5_pricing_section.html` / `q5_pricing_section.css` — Pricing cards with fade-in animation
- `q6_blog_layout.html` / `q6_blog_layout.css` — Blog layout using grid-template-areas
- `q7_loading_animation.html` / `q7_loading_animation.css` — Three-dot CSS loading animation
- `q8_photo_gallery.html` / `q8_photo_gallery.css` — Responsive photo gallery
- `q9_card_flip.html` / `q9_card_flip.css` — 3D card flip on hover
- `q10_responsive_layout.html` / `q10_responsive_layout.css` — Combined Flexbox and Grid layout

## How to run
Open any `.html` file in a web browser. Keep its matching `.css` file in the same folder.

## Notes
- No JavaScript or external CSS frameworks are used.
- Layouts use Flexbox and/or CSS Grid and include responsive media queries.
- Q8 and Q9 use externally hosted image URLs; an internet connection is needed to load those images.
