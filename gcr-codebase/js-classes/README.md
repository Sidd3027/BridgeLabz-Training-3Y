# Assignment 4 — Js Classes

Core JavaScript (ES6+) solutions for all 9 questions.

## Files
- Q1, Q3, Q6 and Q9 are console-based JavaScript examples.
- Q2, Q4, Q5, Q7 and Q8 include an HTML demo page and a separate JavaScript file.

## Run
1. For a browser-based question, open its matching `.html` file in a browser.
2. For console questions, run the `.js` file with Node.js, for example: `node q1_ecommerce_product_manager.js`.
3. No frameworks or external libraries are required.
