# Assignment 2 — JS Operator

Ten separate JavaScript files covering scope, string manipulation, Math methods, arrays, Boolean logic, functions, feedback checks, discounts, FizzBuzz classification, and employee evaluation.

## Run a program
Use Node.js from this folder, for example:
`node q1_scope_conflict_resolver.js`

All programs use core JavaScript and include comments. Change sample values in each file to test different cases.
