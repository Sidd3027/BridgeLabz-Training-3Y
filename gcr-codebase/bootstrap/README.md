# Assignment 10 — Bootstrap 5

Ten responsive Bootstrap practice pages. Each question has a separate HTML file and matching CSS file.

## Pages
1. `company_landing_page.html` — landing page and responsive grid
2. `personal_portfolio_basics.html` — profile, utilities, buttons, and form
3. `product_catalog.html` — responsive product grid and cards
4. `restaurant_menu_page.html` — table, list group, and food image
5. `custom_themed_blog_homepage.html` — custom Bootstrap theme and Google Font
6. `notifications_dashboard.html` — alerts and summary panel
7. `task_tracker_badges.html` — task list and priority badges
8. `pricing_plans.html` — responsive pricing cards
9. `blog_pagination_pager.html` — pagination and pager buttons
10. `travel_agency_showcase.html` — carousel and animated progress bar

## Notes
- Bootstrap 5.3.3 CSS is loaded from the official jsDelivr CDN.
- Each page has its own CSS file.
- Bootstrap's JavaScript bundle is included for the dismissible alert and carousel components.
- Product and destination images load from Unsplash and require an internet connection.
