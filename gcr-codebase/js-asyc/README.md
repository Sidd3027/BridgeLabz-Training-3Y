# Assignment 6 — Asyc Programming with JS

Solutions for all 10 questions using core JavaScript (ES6+), Promises, callbacks, async/await, and error handling.

## How to run
- Most files can be run using Node.js: `node q1_async_coffee_maker.js`
- Q6 uses `fetch()` and includes an optional HTML page for dynamically created product cards. Open `q6_fake_store_products.html` in a browser with an internet connection.
- Each file is independent. Some questions intentionally simulate random failures, so the output can differ between runs.
